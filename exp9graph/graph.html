Aim:

To study Graph

Theory:

A Graph is a data structure used to represent relationships between objects. It consists of nodes (vertices) and edges that connect them. Graphs are widely used in various applications, such as networking, social networks, shortest path algorithms, and scheduling problems.

Types of Graphs:
  • Directed Graph (Digraph): A graph where edges have a direction, meaning they go from one vertex to another.
  • Undirected Graph: A graph where edges do not have a direction and simply connect two vertices.
  • Weighted Graph: A graph where edges have weights or costs associated with them.
  • Unweighted Graph: A graph where edges have no weights.
  • Cyclic Graph: A graph that contains at least one cycle.
  • Acyclic Graph: A graph that does not contain any cycles.
Graph Representations:
  • Adjacency Matrix: A 2D array where a cell (i, j) is **1** if there is an edge from vertex i to vertex j, otherwise **0**.
  • Adjacency List: Each vertex has a list of adjacent vertices. This is a space-efficient representation.
Graph Traversal Techniques:
  • Breadth-First Search (BFS): Traverses the graph level by level using a queue.
  • Depth-First Search (DFS): Traverses the graph by exploring as far as possible along each branch before backtracking, using a stack.

Algorithm:

  1. BFS Algorithm:
    1. Start from a selected node.
    2. Mark the node as visited.
    3. Enqueue the node.
    4. While the queue is not empty:
      • Dequeue a node and process it.
      • Enqueue all its unvisited adjacent nodes.
  2. DFS Algorithm:
    1. Start from a selected node.
    2. Mark the node as visited.
    3. For each unvisited adjacent node, recursively apply DFS.
