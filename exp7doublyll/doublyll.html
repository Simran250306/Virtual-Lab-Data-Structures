Aim:

Implement a Doubly Linked List.

Theory:

A Doubly Linked List (DLL) is a type of linked list where each node holds three pieces of information:
1. Data: The actual value or information stored in the node.
2. Next Pointer: A reference (or pointer) to the next node in the list.
3. Previous Pointer: A reference (or pointer) to the previous node in the list.
This bi-directional linkage makes traversal possible in both directions (from head to tail and tail to head), unlike a singly linked list, which only allows traversal in one direction. As a result, DLLs are especially useful in scenarios where elements may need to be accessed in reverse order, or where frequent insertions and deletions are required.
A Doubly Linked List has the following characteristics:
  • Head Pointer: Points to the first node in the list.
  • Tail Pointer: Points to the last node in the list.
  • Traversal: You can traverse the list from the first node to the last, and vice versa, by following the next and prev pointers.
  • Dynamic Size: The size of the list is not fixed, and nodes can be added or removed dynamically.

    • Algorithm:

    Insertion at End:
    1. Create a new node.
  • Set its prev to the current tail and next to null.
  • Update the current tail's next to point to the new node.
  • Set the tail to the new node.

    • 2. Deletion from End:
  • Set the tail to the previous node.
  • Update the new tail’s next to null.

    • 3. Traversal (Forward):
  • Start from the head and follow next pointers until the end.

    • 4. Traversal (Backward):
  • Start from the tail and follow prev pointers until the beginning.
