Aim:

Parenthesis Checker

Theory:

The Parenthesis Checker is a program that verifies whether a given expression with brackets (parentheses, curly braces, and square brackets) is balanced.
An expression is considered balanced if:
  1. Every opening bracket ((, {, [) has a corresponding closing bracket ), }, ].
  2. Brackets are closed in the correct order.

Algorithm:

  1. Initialize an empty stack.
  2. Traverse the expression character by character:
    • If the character is an opening bracket (, {, [, push it onto the stack.
    • If the character is a closing bracket ), }, ]:
      • If the stack is empty (no opening bracket to match), return false.
      • If the top of the stack matches the closing bracket, pop it.
      • Otherwise, return false (mismatch found).
  3. After traversal, if the stack is empty, the expression is balanced, else it is unbalanced.
