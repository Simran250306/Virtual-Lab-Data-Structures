Aim:

Implement Stack ADT using an array.

Theory:

Stack can be represented using an array. Stack is open at one end and operations can be performed on a single end. We can have different primitive operations on Stack Data Structure.
  1. Push Operation on Stack :
    2. We have declared data array in the above declaration. Whenever we add any element in the „data‟ array then it will be called as “Pushing Data on the Stack”.
    Suppose “top” is a pointer to the top element in a stack. After every push operation, the value of “top” is incremented by one.
  2. Pop Operation on Stack :
    3. Whenever we try to remove an element from the stack then the operation is called POP Operation on Stack.

    7. Exit
  2. Pop():
